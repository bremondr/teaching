# Design Sprint method sheets

## Credit

**Adapted from the Design Sprint method of Jake Knapp, John Zeratsky and Braden Kowitz (Google Ventures).** The original materials are not included. These sheets are the author's own adaptation for teaching (Ondřej Brém), written in his own words, and they are not a copy or a replacement of the original book.

## About

Short handouts, one page each as far as possible, for a facilitator who runs a five-day design sprint with a team: a big challenge is understood on Monday, ideas are sketched on Tuesday, one direction is chosen and storyboarded on Wednesday, a prototype is built on Thursday and tested with five users on Friday. Each sheet has the same structure: why, how (before, during, after), expected outcome, key ideas, and the context (previous and next exercise, supplies).

Language of the materials: English.

## Using it

Open a sheet in the viewer through the table above and print it from the browser (A4). Print only what the day needs. Open the page through the hub address; opening the files straight from disk does not work with the viewer.

## Editing it

Each sheet is one Markdown file in `sheets/`. Keep the one-line credit under the title of every sheet. After an edit run `python3 scripts/check.py`.

## Known limits

- Two sheets, Lightning demos and Sticky decision, are empty templates: their content and time are still to be written.
- The original sheets had illustrations that could not be carried over; only the empathy-map grid in the Map sheet is marked in text.
- The time for the Interview script was not given and is marked as to be confirmed.
- Some sheets have empty fields in the original (key ideas, type of activity); they are marked as such.
