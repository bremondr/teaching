# Interview script

*Adapted from the Design Sprint method (Knapp, Zeratsky, Kowitz). Own adaptation for teaching.*

**Day:** Thursday (prepared while the prototype is built, used on Friday) | **Time needed:** time to be confirmed

A guide for the moderator to run the test smoothly, and a way to check that the test works and the prototype is set up correctly.

## Objectives (Why?)

1. Guide the [5 act interview](05-test-5-act-interview.md).
2. Prepare the questions.
3. Set the context for the testers.

## Instructions (How?)

### Before starting

Re-read the sprint questions.

### The activity

- Write a **short story** that sets the stage: the situation the tester is in when the solution would be used, and an easy reason to do the mission.
- Write a **mission**: a task for the tester, given without instructions on how to do it.
- Prepare **probing questions** to learn how they think.

### When finished

Test the questions, story and mission: are they understandable and achievable?

## Expected outcome (What?)

- A context story.
- A mission for the tester.
- A starting set of questions for the moderator.

## Key ideas

1. Do not lead with your questions.
2. Do not reveal too much before the test.
3. Do not give step-by-step instructions.
