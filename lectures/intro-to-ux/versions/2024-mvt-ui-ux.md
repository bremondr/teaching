# Outline of the 2024 deck "UI & UX" (MVT)

An older generation of this lecture (November 2024), in English, for the MVT course. This is an
outline in my own words, not a copy. The deck was mostly pictures, so many slides carry only a
title. The 2026 deck (`../deck.md`) replaced it.

## 1. Opening
- Title, then a case study from a well-known building in Copenhagen shown in three parts: its UI,
  its UX, and both together (pictures only).
- "What do you want to know?" as an opening question.

## 2. User interface
- Examples of interfaces by context: desktop, smartphones, data visualisation and processing,
  cars, public space, VR and AR, smart devices.
- Definition of UI: the visual layout of an app, made of buttons, text, images, sliders and input
  fields, including screen layout, transitions, animation and micro-interactions.

## 3. User experience
- A guessing game with pictures ("take a guess", "did you get it right?", "try it now", "easier?")
  leading to "make it obvious" and the Norman door.
- UX as UI plus the interactions plus the flow.
- Definition of UX: how smooth, intuitive, logical and positive the use of the app feels; it
  depends on how easy the UI elements are to use.
- UI changes over time: two Czech public web examples before and after a redesign (pictures only).

## 4. Helpful rules
- The ten usability heuristics (visibility of system status, match with the real world, user
  control, consistency, error prevention, recognition over recall, flexibility, minimalist design,
  error recovery, help and documentation).
- Activity: pick a website or app you use and check it against the ten; then pick a more complex
  site and look at how it uses the Gestalt principles.

## 5. What is missing
- Service design: the UI, the UX of using it, and then all touchpoints together.
- Helpful resources (a list of well-known UX sites and method collections).

## Compared with 2026
- Only in 2024: the UI examples by context, the separate UI and UX definitions, the Norman door
  guessing game, the ten heuristics as an activity, Gestalt principles, service design.
- Only in 2026: the artifact jury warm-up, expert definitions of UX, the six-step design process
  with methods, the worst-UI challenge and exercise, dark patterns, the air-conditioning brief.
